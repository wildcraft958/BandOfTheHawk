# Requirements for the fraudsim closed-loop red/blue pipeline.
# Versions pinned to the known-good GPU environment (torch 2.11.0 + cu130).
#
# INSTALL torch FIRST from the CUDA index so pip does not pull the CPU build off
# PyPI:
#   python3 -m venv myenv && source myenv/bin/activate
#   pip install --upgrade pip
#   pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu130
#   pip install -r requirements.txt
#
# Verify the GPU is visible:
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#   -> 2.11.0+cu130 True
#
# Then run:
#   CUDA_VISIBLE_DEVICES=0 python main.py --profile server --models
#
# Note on where the GPU is actually used: the generation and embedding models
# run once, in the `text` stage, and their output is cached into the pool. The
# reinforcement-learning networks are small multilayer perceptrons and the
# defender is gradient-boosted trees, so the remaining stages are bound by the
# simulation loop rather than by the device.
